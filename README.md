# יזמות לילדים

אתר טלפון לשבוע אחד, רק לאמיליה ולאוולין. בלי חשבון, בלי סיסמה, בלי חנות אפליקציות.

הכסף נשאר אצל אמא. האתר רק זוכר איפה עומדות.

## איך פותחים בטלפון

אחרי שהאתר עולה ב-GitHub Pages, פותחים את הקישור בטלפון ושומרים למסך הבית.

אם אין עדיין קישור: פותחים את `index.html` בדפדפן.

## מה יש בפנים

1. בחירת כרטיס אחד: לימונדה ליד הבית, צמידים, ברכות כתובות, או עוזרות בבית.
2. מחיר אחד, ולמי מוכרות. רק משפחה או שכן מוכר. דוכן לימונדה רק כשאמא בבית.
3. רשימת קניות. בלימונדה: 8 לימונים, סוכר, 20 כוסות, קרח, קנקן, שלט. כוס ב-5 שקלים. תקציב זרע 50 שקל.
4–5. מכינות.
6. יום מכירה אחד. אוולין סוחטת ומוזגת, אמיליה מוכרת וסופרת.
7. סופרות מה נשאר. לבזבז, לחסוך, לתת. היום נסגר גם אם נמכר אפס.

הורים אחרים מחכים עד שהשבוע הזה ייגמר אצלכן.
